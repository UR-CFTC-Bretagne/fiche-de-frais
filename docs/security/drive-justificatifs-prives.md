# Lecture privée de justificatifs Drive

Prototype non déployé. Le lecteur exige une liaison interne entre identifiant du fichier, demandeur et dossier autorisé. La passerelle Apps Script contrôle le dossier parent direct, la taille et le type MIME. Les tests sont fictifs.

Le registre d'attribution doit être alimenté exclusivement par un serveur authentifié. Il reste à établir les habilitations, la protection contre la substitution de fichiers, la vérification des versions et les contrôles antimalware. Aucun accès Drive réel n'a été effectué.
