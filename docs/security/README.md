# Sécurité et données personnelles

Dépôt public : ne pas committer de comptes, de RIB, de justificatifs ni de clés. Les données peuvent révéler une appartenance syndicale. Exiger validation RGPD et habilitations avant tout accès réel. Appliquer le moindre privilège, protéger les URL Drive, journaliser les actions financières et documenter les durées de conservation.
