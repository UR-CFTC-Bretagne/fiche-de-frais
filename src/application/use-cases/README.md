# Cas d'usage à implémenter

- Créer et modifier une note de frais.
- Soumettre, contrôler, corriger et approuver une demande.
- Enregistrer les justificatifs et leur traçabilité.
- Ventiler les montants URB / AGFPN et calculer avec un barème daté validé.
- Enregistrer un paiement de manière idempotente.
- Exporter des états analytiques vérifiables.

Chaque cas d'usage doit vérifier les habilitations côté serveur.
